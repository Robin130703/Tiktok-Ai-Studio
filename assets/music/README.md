# Hintergrundmusik

Hier liegen die lizenzfreien Tracks für den Videoschnitt (`npm run video`, Issue #9).
Der Schnitt nimmt die alphabetisch erste Datei (`.mp3`, `.wav`, `.ogg`, `.m4a`, `.aac`,
`.flac`) aus diesem Ordner; mit `--music <datei>` lässt sich ein anderer Track wählen,
mit `--no-music` wird auf Musik verzichtet. **Ohne Musikdatei läuft der Schnitt
trotzdem** (mit Hinweis, ohne Hintergrundmusik).

Zurzeit liegt **keine** Musikdatei im Repo. Es wurde bewusst nichts eingecheckt, dessen
Lizenz nicht geklärt ist.

## Regeln für neue Tracks

- Nur Musik, die für kommerzielle Nutzung und Veröffentlichung auf TikTok erlaubt ist:
  Public Domain / CC0, oder eine Lizenz, die das ausdrücklich zulässt (z. B. CC BY mit
  Namensnennung im Videotext, dann hier vermerken).
- Keine Tracks aus Streaming-Diensten, Spielen, Filmen oder mit Content-ID-Ansprüchen.
  Keine "Free for personal use"-Lizenzen und keine Lizenzen mit NC (nicht kommerziell).
- Jede Datei wird in der Tabelle unten mit Quelle, Lizenz und Abrufdatum erfasst, bevor
  sie eingecheckt wird. Ohne Eintrag wird der Track nicht eingecheckt.
- Dateigröße gering halten (empfohlen: MP3, höchstens wenige MB).
- Die Lautstärke wird beim Schnitt automatisch abgesenkt (siehe `docs/video-assembly.md`);
  der Track muss nicht vorab angepasst werden.
